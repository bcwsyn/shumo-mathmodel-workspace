# Typst Reference — MathModel Project Adaptation

Adapted from QuantumBFS/sci-brain (MIT). The project's `typst-author` skill is authoritative.

- Use project-approved `.typ` competition templates.
- Prefer vector PDF/SVG and compile before delivery.
- Use native `grid`, `rect`, and fixed-width `box` for text-heavy comparisons.
- Use CeTZ only when it materially improves the mathematical argument.
- Define symbols before use and keep labels stable across revisions.
- Check the compile log for unresolved citations and warnings.
