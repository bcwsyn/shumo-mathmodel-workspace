# 数学建模 Python 工程标准

代码应体现有丰富数值计算和算法工程经验的工程师风格：结构清晰、可维护、数值稳定、错误处理完整，同时保留有证据的性能优化、调试和版本演进痕迹。

## 技术栈

- 核心：Python、NumPy 1.24+、SciPy 1.10+、pandas 2.0+、Matplotlib 3.7+。
- 按题型选用：CVXPY、scikit-learn、statsmodels。
- 仅在确有热点循环时选用 Numba；仅在矩阵确实稀疏时使用 `scipy.sparse`；仅在数据规模需要时使用内存映射。
- 使用项目确认的真实解释器和已安装版本。缺少依赖时报告并等待安装授权，不虚构版本或运行结果。

## 单文件主实现

默认采用“单文件主实现 + 完整配套文件”：

```text
code/
  main.py                 # 数据层、模型层、验证层、可视化层和入口编排
  audit_manifest.json
tests/
  test_main.py
results/
figures/
logs/
reports/
requirements.txt          # 或等价的依赖版本记录
```

在 `code/main.py` 内用明确分区、类和函数保持逻辑模块化：

1. 配置与常量。
2. 自定义异常。
3. 数据读取、校验与预处理。
4. 模型、算法与数值求解。
5. 结果校验与评价。
6. 可视化与文件输出。
7. CLI 和主流程编排。

若单文件已明显损害可读性、测试隔离或复用性，可在 G2/G3 报告中说明理由后拆分为少量模块；不得为了形式机械拆文件，也不得把所有逻辑堆进一个超长函数。

## 架构与代码质量

- 使用 `dataclass` 或集中字典管理路径、随机种子、模型参数和绘图选项。
- 使用 `logging`，不用 `print` 充当日志；支持 DEBUG、INFO、WARNING 和 ERROR。
- 定义并区分数据错误、数值错误、配置错误等自定义异常。
- 函数保持单一职责，原则上不超过 50 行；确因公式连续性或算法内核需要超长时，记录理由并测试。
- 核心公开 API 使用适量类型注解；辅助函数不过度标注。
- 核心 API 使用 Google 或 NumPy 风格 docstring，说明参数、返回值、异常、形状、单位和适用条件。
- 注释解释“为什么”：公式来源、数值稳定性、单位、约束方向、性能权衡和非显然分支；避免逐行翻译代码。
- 使用 `pathlib` 和显式配置，不写死本机绝对路径，不覆盖原始数据，不记录密钥。

## 数值计算

- 概率或似然计算需要时使用 log-sum-exp。
- 对指数、概率、分母和物理边界使用有依据的 `np.clip` 或显式阈值，避免溢出和非法值。
- 解线性方程优先使用 `np.linalg.solve` 或适合问题结构的分解，不显式求逆。
- 特殊函数使用 `scipy.special`；优化和积分使用与问题结构匹配的 SciPy 接口。
- 检查矩阵条件数、求解器状态、约束松弛量、迭代终止原因和结果物理范围。
- 输入校验至少覆盖 shape、dtype、取值范围、缺失值、重复值和单位。
- 概率、权重、流量、容量等输出执行合理性检查；关键假设可用 `assert`，外部输入错误使用明确异常。
- 使用数值优化且可获得梯度时，执行解析梯度与有限差分梯度检查；无梯度或不适用时说明。

## 性能与真实工程痕迹

- 先用计时或 profiling 找到热点，再向量化、缓存、稀疏化、Numba 加速或内存映射。
- 可为关键函数提供 `@timer` 装饰器或等价计时记录，但不为无性能风险的辅助函数增加噪声。
- 使用 `logging.debug` 记录关键形状、参数摘要、收敛过程和中间指标，生产运行可关闭。
- 保留 1–2 处真实的版本演进注释，例如旧实现、优化原因和基准结果；只有实际比较过才能写“快 N 倍”，不得伪造工程痕迹。
- `TODO`/`FIXME` 只用于真实未决事项，并在最终交付前清除影响正确性或复现性的标记。

## 测试、图表与复现

- 测试覆盖正常输入、空数据、单样本、缺失值、错误形状、极端值和不可行条件中与题目相关的边界。
- 测试断言具体数值、容差、异常类型或约束状态，不只断言“没有报错”。
- 随机过程使用集中配置的种子，默认 `42`；多次运行实验使用可记录的种子序列。
- 学术图表统一字体、字号、线宽、色板和图例位置，支持中英文混合标签；优先导出 PDF/SVG，同时按需提供高分辨率 PNG。
- 图表函数只消费已保存的结果数据，不重新计算或偷偷改写核心指标。
- 结果记录 Python、依赖版本、随机种子、运行参数、开始/结束时间、总耗时和产物哈希。
- 最终必须提供从原始附件或已声明的中间数据到结果和图表的一键复现入口。
