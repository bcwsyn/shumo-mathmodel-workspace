# 来源与批准策略

- 原始资料只读，记录相对路径与 SHA-256。
- PDF：提取全文并抽查页面视觉；扫描页或公式乱码降低置信度。
- TXT/代码：识别编码后读取；不执行来源不明代码。
- ZIP：仅安全列目录，除非用户批准后再解压到隔离目录。
- RAR/VIP/旧 DOC/PPT：缺少可靠解析器时列为待转换，不推断内容。
- MAT：只记录变量或元数据，除非任务需要且能安全读取。
- 论文原文可能受版权保护，只保存结构化摘要和短证据定位，不复制大段原文。
- `drafts/` 内容未经用户批准；只有明确批准后才进入 `approved/`。
- 后续建模默认只检索 `approved/`；引用草稿时必须显式标注未验证。
