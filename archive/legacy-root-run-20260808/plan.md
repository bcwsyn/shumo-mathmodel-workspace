# 方案

本项目按“学习复现”模式完成 2024 年高教社杯全国大学生数学建模竞赛 B 题《生产过程中的决策问题》。题面来源为 `C:\Users\lw195\Desktop\B题\B题.pdf`；该文件已完成两页视觉核对与文本提取。除竞赛格式与中文写作习惯外，不自动声称满足真实参赛提交规则。

## 用户偏好

- 项目模式：学习复现（用户未要求直接参赛合规验收）
- 排版引擎：Typst（项目固定）
- 竞赛类型：2024 年高教社杯全国大学生数学建模竞赛（CUMCM）
- 论文语言：中文（由题面语言确定）
- 子问题数量：4（由题面明确编号确定）
- 审批方式：逐阶段人工审批（“按流程完成”）；每个审批门须获得明确批准

## 建模方向（G0 初步识别，未定稿）

1. 问题 1：以二项分布的一侧置信推断为基线，比较固定样本方案与序贯抽样方案；样本量“尽可能少”的可操作定义和无差异区间在 G1 明确。
2. 问题 2：将零配件检测、成品检测、拆解和退换循环表示为有限策略集上的更新-报酬过程，按单位成功销售产品的期望利润/成本比较策略。
3. 问题 3：把多工序装配关系抽象为有向无环生产网络，以动态规划或 MDP 型递推扩展问题 2，并对图 1、表 2 实例求解。
4. 问题 4：以抽样所得缺陷率的区间或后验分布传递不确定性，比较期望利润、最坏情形和风险敏感决策。

## 风险控制

- 不把题面未给出的批量规模、检测误差、缺陷独立性和重复拆解规则当作事实；先在 G0 标注，G1 以情景假设与灵敏度处理。
- 问题 1 的置信结论不能仅以样本比例替代；后续实现须使用可复核的一侧二项置信界或等价检验。
- 所有生产策略的结果均须逐项回代验证缺陷传播、成本、售价、退换和拆解逻辑；循环过程须检验期望成本收敛。
- G1 批准前不创建正式求解代码；G3 批准前不写论文正文；G6 批准前不生成预览 PDF。
