# 新建模项目目录

每道新题创建一个独立目录：projects/<YYYYMMDD>-<题目短名>/。

题面与附件放入 inputs/；该项目的 plan.md、todo.md、代码、结果、图表、论文和报告全部保存在同一项目目录内，不复用其他题目的产物。

## 现有历史项目

- `2021try1/`：2021 年历史项目，包含论文、代码、结果和提交产物。
- `CUMCM2018A_HighTemperatureClothing/`：2018 A 题高温服装项目，保留完整代码与实验产物；独立虚拟环境已清理，运行前按 `requirements.txt` 重建。

历史项目保留原目录名，避免无必要地改写论文、日志和审计证据中的旧名称。
