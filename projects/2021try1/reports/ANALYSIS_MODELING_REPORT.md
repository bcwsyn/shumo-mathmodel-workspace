## 2. 题意与三个子问题

### 2.1 问题一：正上方观测时的理想抛物面

- 已知条件：`α=0°，β=90°`，基准球面、焦面关系、300 m 工作口径以及面板调节约束。
- 待确定对象：对称轴沿天体方向、焦点位于物理有效焦面交点的理想旋转抛物面，包括其顶点或等价参数。
- 评价核心：理想抛物面本身要与可调反射面相容，不能只满足解析焦点关系而导致大面积节点位移或索长变化不可行。
- 与后续关系：给出理想抛物面的定义方式和约束处理方法，为问题二的任意指向情形提供基准。
- G3 预期展示：球面与候选抛物面的轴截面对比、径向偏差分布、调节可行区间表。

### 2.2 问题二：指定天体方向下的抛物面与反射面调节

- 已知条件：`α=36.795°，β=78.169°`，附件 1–3 的节点、促动器和三角网拓扑。
- 决策对象：理想抛物面的顶点/焦距参数，以及 300 m 口径内相关节点位置和促动器伸缩量。
- 目标：在促动器、下拉索和主索长度变化约束下，使工作反射面尽量贴近理想抛物面。
- 硬约束：促动器伸缩量 `[-0.6,0.6] m`；每条主索相对长度变化绝对值不超过 `0.0007`；下拉索逐节点保持基准长度；非工作区节点的处理方式须明确。
- 输出：按附件 4 的三个工作表格式生成 `result.xlsx`，数值至少保留 3 位小数。
- 与其它问题的依赖：继承问题一确定的抛物面定义；其调节方案是问题三接收比计算的唯一正式输入。
- G3 预期展示：节点位移云图、促动器伸缩量分布与边界占用、主索约束松弛量分布、拟合残差统计与最差点清单。

### 2.3 问题三：调节面与基准球面的接收比比较

- 输入：问题二的正式调节后节点/面板几何、馈源舱位置和直径 1 m 的接收圆盘。
- 计算对象：来自天体的平行射线经各面板反射后是否命中馈源舱有效圆盘，以及相应的信号权重。
- 输出：调节后工作面的接收比、相同 300 m 口径下基准球面的接收比、二者差异与误差/收敛性说明。
- 约束与评价：两种反射面必须使用相同的口径选取、面板离散、入射功率权重和命中判据，避免口径或分母不一致造成伪提升。
- G3 预期展示：馈源平面落点图、命中圆盘示意、接收比对比表、面板细分/采样收敛曲线。

## 4. 假设敏感性预检

### 4.1 模糊表述及解释

1. **300 m 口径的选取**
   - 解释 A：以观测轴为中心，在垂直于观测轴的口径平面上投影半径不超过 150 m。
   - 解释 B：以球面某中心点为中心，按三维欧氏距离或球面测地距离截取半径 150 m。
   - 初步判断：A 保持旋转抛物面的圆形投影口径，且在斜指向下仍与物理口径一致；B 会产生不同的斜向边界。

2. **直线 `SC` 与焦面的交点 `P`**
   - 同心焦面球与整条直线有两个交点。
   - 物理有效交点应在球心 `C` 朝反射面一侧，即若天体方向单位向量为 `u`，候选位置为 `P=-(R-F)u`；另一交点位于天体一侧，不能被凹面汇聚使用。

3. **“确定理想抛物面”**
   - 解释 A：焦点和轴固定后仍优化顶点/焦距，使其与基准球面或可调节点的整体偏差最小。
   - 解释 B：直接把题给的 `F=0.466R` 当作抛物线焦距。
   - 初步判断：题中 `F` 是基准球面与焦面两同心球的半径差，不应未经推导直接等同于工作抛物面的焦距。

4. **节点运动方式**
   - 解释 A：主索节点近似只沿球心径向移动，促动器与下拉索给出等价径向控制。
   - 解释 B：仅促动器顶端径向移动，节点可在三维空间调整，但必须同时满足逐节点下拉索定长和索网约束。
   - 初步判断：只依据题面，B 是更完整的几何约束；但若不补充索网力学平衡会欠定。G1 应比较“径向位移简化”与“显式定长几何”并说明可辨识性。

5. **“尽量贴近”的目标函数**
   - 可用节点到抛物面的轴向残差、正交距离、面积加权平方残差或最大残差。
   - 不同指标会改变顶点和边界节点结果；G1 需至少比较均方误差与最大误差/高分位误差，避免少数面板严重偏离。

6. **接收信号权重**
   - 解释 A：每个面板或采样点等权。
   - 解释 B：按入射波在面板上的投影面积计权。
   - 初步判断：平行波单位通量下，B 更符合能量口径；仍需对边界面板和曲面离散做一致处理。

### 4.2 快速验算与递进性检查

- 数据半径接近 `300.4 m` 而不是严格 `300 m`，说明所有后续几何量应由附件恢复，题面整数仅为近似描述。
- 促动器上下端点几乎严格沿球心径向，支持“促动器径向伸缩”的字段解释；下拉索长度却跨较大范围，证明不能把促动器长度与下拉索长度混为一谈。
- 用三角面板恢复出恰好 6525 条唯一边，证明附件 3 足以重建题面要求的主索长度约束，不需另行猜测邻接。
- 若把焦面球的天体侧交点作为焦点，焦点处在凹面背向的错误一侧，问题三无法得到合理汇聚，故该解释被排除。
- 若斜指向时仍按全局 `xy` 平面截取 300 m 圆口径，则选区不会随天体方向正确旋转，问题二相对问题一新增的方向参数不能充分生效，故应以观测轴构造局部坐标系。
- 若接收比直接按节点命中率计算，会忽略三角面板面积差异（本数据约 `51.36–66.77 m²`）及入射投影面积，可能产生系统偏差，故节点计数只能作基线，不能直接作为最终物理定义。

### 4.3 最终采用的解释（G0 已批准）

用户已批准以下口径作为 G1 推导基础：

- 观测方向采用图 5 的常规方位角/仰角单位向量；物理焦点取 `P=-(R-F)u`。
- 300 m 口径定义为垂直于观测轴的圆形投影口径。
- `F=0.466R` 仅用于确定焦面位置，不直接当作抛物线焦距。
- 优先建立包含径向位移简化的可辨识模型，同时用下拉索定长几何检查其物理一致性；若完整三维模型欠定，则明确采用简化的理由和误差。
- 接收比按三角面板投影面积加权的射线命中比例定义，并用等权/不同细分密度作为敏感性对照。

## 6. G1 必须解决的未决问题

1. 节点是否严格限制为球心径向位移，还是允许三维位移并引入力学/正则化条件。
2. 理想抛物面的自由参数、拟合距离定义和面积权重。
3. 300 m 边界相交面板是按中心、顶点、投影裁剪面积还是细分采样纳入。
4. 非工作区节点固定时，跨边界主索如何纳入 `0.07%` 约束。
5. 调节目标是先独立确定理想面再投影到可行集，还是联合优化理想面与促动器；两者需比较题意一致性和可解释性。
6. 面板反射法向采用三顶点平面、球面切平面还是细分曲面近似，以及网格收敛判据。
7. `result.xlsx` 应输出全部 300 m 口径内节点还是还包含边界参与节点；须与口径定义一致。

## 7. G0 结论

材料完整且内部一致，可进入建模方案设计；共 3 个顶层子问题，依赖链为“理想抛物面定义 → 指定方向调节与输出 → 接收比评价”。当前没有数据层面的硬阻塞，但有七项几何/物理口径需要在 G1 形成候选模型比较后确定。

## 8. G1 总体建模框架

采用“固定焦点的一参数理想抛物面 + 径向节点运动 + 下拉索精确几何映射 + 主索约束优化 + 面板级射线追踪”的统一框架。

1. 从附件恢复基准球半径、节点单位径向、主索边、下拉索长度和促动器径向。
2. 对每个观测方向建立局部轴向坐标，并按垂直于观测轴的投影圆选取 300 m 工作口径。
3. 在焦点固定于焦面交点的条件下，用一个焦距参数描述全部候选旋转抛物面。
4. 以促动器行程和主索长度变化的最大归一化占用率确定“硬件友好”的理想抛物面。
5. 将理想抛物面与各节点径向射线的交点作为目标位置，在全部精确约束下求最接近的可行工作面。
6. 将调整后的三角面板视为局部平面镜，通过确定性细分射线追踪计算馈源舱接收比，并与基准球面采用同口径比较。

两个方向的实际规模为：

| 方向 | 300 m 口径内节点 | 与活动节点关联的主索边 | 跨口径边界主索 | 全部顶点在口径内的面板 | 跨边界面板 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `α=0°，β=90°` | 706 | 2205 | 175 | 1325 | 175 |
| `α=36.795°，β=78.169°` | 692 | 2165 | 179 | 1295 | 179 |

该规模适合使用稀疏确定性优化；不需要把约 700 个连续变量直接交给遗传算法。

## 9. 符号与坐标

| 符号 | 含义 |
| --- | --- |
| `C=0` | 基准球心 |
| `R_i=||x_i||` | 第 `i` 个节点的基准半径 |
| `R=N^{-1}ΣR_i` | 数据恢复的基准球半径 |
| `F=0.466R` | 基准球面与焦面球的半径差 |
| `q=R-F=0.534R` | 焦面球半径 |
| `u` | 从球心指向天体的单位向量 |
| `k=-u` | 从球心指向工作反射面的轴向单位向量 |
| `P=qk` | 馈源舱接收平面中心/抛物面焦点 |
| `n_i=x_i/R_i` | 节点 `i` 的球心径向单位向量 |
| `y_i` | 节点沿 `n_i` 向球心的位移，向内为正 |
| `x_i(y_i)=x_i-y_i n_i` | 调整后节点坐标 |
| `a_i,b_i` | 促动器下端点、基准态上端点 |
| `h_i=b_i/||b_i||` | 促动器向外径向单位向量 |
| `σ_i` | 促动器顶端向球心的伸缩量，向内为正 |
| `L_i=||x_i-b_i||` | 第 `i` 根下拉索基准长度 |
| `l_ij=||x_i-x_j||` | 主索边 `(i,j)` 的基准长度 |
| `ε=0.0007` | 主索相对长度变化上限 |

方位角、仰角转为

```math
u=(\cos\beta\cos\alpha,\ \cos\beta\sin\alpha,\ \sin\beta),\qquad k=-u.
```

对任意点 `x` 定义轴向坐标和离轴距离

```math
t=x\cdot k,\qquad \rho(x)=\sqrt{\|x\|^2-t^2}.
```

工作节点集合固定按基准位置选择：

```math
\mathcal I(k)=\{i:\ x_i\cdot k>0,\ \rho(x_i)\le 150\}.
```

口径外节点令 `y_i=0`，但所有与活动节点相连的跨边界主索仍进入约束。

## 10. 模型假设

1. 基准球心为坐标原点，半径使用附件节点半径均值，而不是题面近似整数。
2. 每个节点只有一个可辨识控制自由度：沿其基准球心径向移动。该假设与“促动器沿基准球面径向安装”一致，并避免在缺少索网受力、预张力和材料参数时引入不可辨识的三维位移。
3. 促动器顶端严格沿自身基准径向运动；下拉索逐节点保持附件确定的基准长度。
4. 口径外节点固定，跨边界主索仍满足 `0.07%` 长度变化限制。
5. 反射面板间缝隙使面板不会因相邻面板接触而额外变形；面板在射线模型中按调整后三顶点确定的局部平面处理。
6. 电磁波为平行直线传播，面板为理想镜面、无孔且无能量吸收；不同表面的接收比使用完全一致的功率权重。
7. 附件坐标精度足以支持控制计算；坐标舍入误差在稳健性分析中单独扰动检验。
8. 所有非凸优化结果称为“经多起点验证的最佳可行解”，除非后续获得全局最优证明。

## 12. 问题一：正上方观测的理想抛物面

### 12.1 抛物面参数化

焦点 `P=qk` 固定。令抛物面焦距为 `f>0`，顶点轴向半径为

```math
v=q+f,\qquad V=vk.
```

旋转抛物面写成

```math
\rho(x)^2=4f\,[v-x\cdot k].
```

因此全部候选面只有一个自由参数 `f`。当 `f=F` 时 `v=R`，即顶点位于基准球面，是候选 A。

### 12.2 理想目标节点

节点径向射线写为 `x=\lambda n_i`。令

```math
c_i=n_i\cdot k,\qquad a_i^{(\rho)}=1-c_i^2.
```

其与候选抛物面的正半径交点满足

```math
a_i^{(\rho)}\lambda_i^2+4fc_i\lambda_i-4fv=0.
```

取靠近基准球面的正根；当 `a_i^{(\rho)}=0` 时有 `\lambda_i=v/c_i`。目标径向位移为

```math
y_i^\star(f)=R_i-\lambda_i(f),\qquad i\in\mathcal I(k),
```

口径外令 `y_i^\star=0`。

### 12.3 下拉索与促动器的精确映射

促动器顶端调整后为

```math
b_i(\sigma_i)=b_i-\sigma_i h_i.
```

下拉索定长给出

```math
\|x_i-y_i n_i-b_i+\sigma_i h_i\|^2=L_i^2.
```

记 `d_i(y)=x_i-b_i-y n_i`，则

```math
\sigma_i^2+2[h_i\cdot d_i(y)]\sigma_i+\|d_i(y)\|^2-L_i^2=0.
```

从两个根中取在 `y=0` 时等于 `0`、并随 `y` 连续的根，记作 `\sigma_i(y)`。判别式小于零代表该目标节点在当前运动假设下不可达。

### 12.4 硬件友好理想面

对每个候选 `f`，把 `y_i^\star(f)` 代入促动器映射和所有关联主索，定义

```math
U_\mathrm{act}(f)=\max_{i\in\mathcal I}\frac{|\sigma_i(y_i^\star)|}{0.6},
```

```math
U_\mathrm{edge}(f)=
\max_{(i,j)\in\mathcal E_\mathcal I}
\frac{\left|\|x_i(y_i^\star)-x_j(y_j^\star)\|/l_{ij}-1\right|}{0.0007},
```

```math
U(f)=\max\{U_\mathrm{act}(f),U_\mathrm{edge}(f)\}.
```

判别式无效时令 `U(f)=+\infty`。问题一的理想焦距定义为

```math
f_1^\star=\arg\min_{f>0}U(f).
```

若多个 `f` 的 `U` 在数值容差内相同，用面积权重 `w_i` 下的

```math
E_\mathrm{move}(f)=\sum_i w_i[y_i^\star(f)]^2
```

作为第二判据。`w_i` 取相邻三角面板面积各分配三分之一得到的节点面积权重。

### 12.5 求解与校验

- 先以 `f=F` 为中心作确定性一维网格搜索，搜索区间由中心节点和全体促动器的可达判别式自动扩张/截断，不人为假定固定焦距区间。
- 对最优网格邻域使用有界一维局部精化；非光滑点同时保留相邻网格候选。
- 分别报告候选 A、B、C 的 `U_act`、`U_edge`、均方位移和最大位移。
- 将得到的 `V_1=(q+f_1^\star)k` 回代焦点公式，检查焦点严格为 `P`。

## 13. 问题二：指定方向下的调节模型

### 13.1 理想抛物面

对 `α=36.795°，β=78.169°` 重新构造 `u,k,P` 和活动集合，并使用问题一完全相同的硬件占用率准则得到 `f_2^\star`。理想抛物面顶点为

```math
V_2=(q+f_2^\star)k.
```

重新优化 `f` 而不是简单旋转问题一数值，是因为离散节点、促动器方向和口径边界并非严格旋转对称；连续球面几何仍由候选 `f=F` 提供对照。

### 13.2 最接近理想面的可行工作面

决策变量为 692 个活动节点的径向内移量 `y_i`；口径外节点固定为零。第一阶段求

```math
\min_y\quad
J(y)=\sum_{i\in\mathcal I}w_i\,[y_i-y_i^\star(f_2^\star)]^2
```

满足

```math
-0.6\le \sigma_i(y_i)\le 0.6,\qquad i\in\mathcal I,
```

```math
(1-\epsilon)l_{ij}
\le \|x_i-y_i n_i-x_j+y_j n_j\|
\le(1+\epsilon)l_{ij},
\qquad (i,j)\in\mathcal E_\mathcal I,
```

以及每个促动器映射判别式非负。跨边界边使用口径外端点 `y_j=0`。

若最小加权误差为 `J^\star`，第二阶段在

```math
J(y)\le J^\star(1+10^{-6})+10^{-12}
```

下最小化最大节点偏差

```math
\min z,\qquad |y_i-y_i^\star|\le z,
```

从而在不显著损失平均贴合度的情况下抑制局部最差误差。

### 13.3 顺序凸化求解

1. 以原始球面 `y=0` 作为严格可行起点，同时测试目标投影 `y=y^\star` 是否已经可行。
2. 在当前迭代点对每条精确主索长度和单变量促动器映射作一阶线性化。
3. 在信赖域 `|\Delta y_i|\le\tau` 内求稀疏凸二次子问题。
4. 对候选步长进行精确下拉索、促动器和主索回代；若约束恶化则缩小 `\tau`，若精确可行且目标下降则接受。
5. 从 `y=0`、可行化后的 `y^\star` 以及二者的若干确定性凸组合启动，保留目标最小的精确可行解。
6. 用精确约束非线性求解器对最佳解作局部精修；后端及版本在 G2 实测后记录，未实测前标记 `UNVERIFIED`。

停止条件：

- 最大径向步长 `<10^{-7} m`；
- 连续两次相对目标变化 `<10^{-9}`；
- 促动器界限的最大绝对超差 `<10^{-8} m`；
- 主索相对变化超出 `0.0007` 的最大量 `<10^{-10}`。

上述是数值验收容差，不是附加物理约束。

### 13.4 输出接口

按附件 4 复制模板生成 `result.xlsx`：

1. “理想抛物面顶点坐标”：写入 `V_2` 的 X/Y/Z。
2. “调整后主索节点编号及坐标”：按附件 1 原顺序写入 300 m 口径内 692 个节点及 `x_i(y_i)`。
3. “促动器顶端伸缩量”：按相同节点顺序写入 `σ_i(y_i)`。

内部结果保留双精度；工作簿显示和存储不少于 3 位小数。写出后重新读回并逐行与内部结果核对，避免排序错位或单位错误。

## 14. 问题三：面板级接收比

### 14.1 入射与反射

电磁波传播方向为 `d=k`。对每个调整后三角面板，按三顶点叉积求单位法向 `m`，并统一定向到天体侧，使 `d\cdot m<0`。反射方向为

```math
r=d-2(d\cdot m)m.
```

馈源接收平面过 `P` 且法向为 `u=-k`。从面板采样点 `p` 出发的反射线与馈源平面交点为

```math
\tau=\frac{(P-p)\cdot u}{r\cdot u},\qquad
q_p=p+\tau r.
```

只有 `\tau>0` 且

```math
\|q_p-P\|\le 0.5
```

时，该采样单元被馈源有效圆盘接收。

### 14.2 面板细分和功率权重

- 将每个三角面板作确定性等面积重心细分；每个微三角形用中心点代表位置，使用母面板法向。
- 只有满足 `\rho(p)\le150` 的微三角形进入 300 m 投影口径，因而跨边界面板按实际细分面积部分纳入。
- 单元反射信号权重取入射投影面积

```math
\omega_s=A_s|d\cdot m_s|.
```

接收比定义为

```math
\eta=
\frac{\sum_s\omega_s\,\mathbf 1(\tau_s>0,\ \|q_s-P\|\le0.5)}
{\sum_s\omega_s}.
```

细分级别逐次加倍，直至接收比绝对变化连续两次小于 `10^{-4}`；同时报告等权结果作为敏感性对照。

### 14.3 对照

- 调节后工作面：使用问题二正式节点坐标。
- 基准反射球面：使用附件 1 原始节点坐标。
- 两者共享相同的三角拓扑、300 m 投影口径、细分级别、入射方向、馈源平面和面积权重。
- 额外在解析理想抛物面上抽样，检查反射线是否汇聚到 `P`，作为反射公式和符号方向的单元校验。

最终报告 `η_work`、`η_base`、绝对提升 `η_work-η_base` 和相对提升；当 `η_base` 过小导致相对提升不稳定时，以绝对提升为主。
