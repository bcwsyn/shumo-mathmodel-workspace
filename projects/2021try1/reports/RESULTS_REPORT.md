理想抛物面候选包括几何焦距、加权最小二乘焦距和硬件友好焦距。正式工作面使用多起点顺序凸化：子问题以面积权重节点位移均方误差为目标，线性化主索与促动器约束；每一步都回到原始非线性几何精确检查。L2 解之后在不突破均方误差容差的前提下精修最大节点误差。

问题三对每个三角面板作等面积微三角形确定性细分，按投影面积加权，以半径 0.5 m 的馈源圆盘为命中区域。基准面与调节面使用完全相同的面板、口径、细分和权重口径。

## 4. 问题三：接收比

64 阶微三角形细分的投影面积加权结果：

| 表面 | 接收比 |
| --- | ---: |
| 基准球面 | 0.00811012 |
| 调节工作面 | 0.01075298 |
| 绝对提升 | 0.00264286 |
| 相对提升 | 32.5872% |

从 32 阶增加到 64 阶时，基准面接收比变化 `9.42×10^-7`，工作面变化 `1.40×10^-5`，分别约为最终值的 0.012% 和 0.130%。因此 64 阶结果已足以支持接收比提升方向与数量级结论。

## 5. 稳健性与敏感性

在 16 阶细分下，把投影口径半径从 149.5 m 调到 150.5 m：

| 半径 | 基准面接收比 | 工作面接收比 | 相对提升 |
| ---: | ---: | ---: | ---: |
| 149.5 m | 0.00806220 | 0.01134351 | 40.70% |
| 150.0 m | 0.00800792 | 0.01126826 | 40.71% |
| 150.5 m | 0.00795501 | 0.01119322 | 40.71% |

同一组实验中改用面板等权后，基准面与工作面的接收比变化均小于约 `4×10^-5`，且工作面优于基准面的结论不变。16 阶敏感性结果用于比较扰动方向，不替代 64 阶主结果。
