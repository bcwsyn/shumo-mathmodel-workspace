# V9.0 教师意见落实版

本目录以 V8.1 DOCX 为只读来源，非破坏性生成 V9.0 交付件。

## 重建

在已具备项目 Python 依赖的 Windows 环境中运行：

```powershell
python .\build_v9_teacher_revision.py
```

脚本读取 OneDrive 中的 V8.1 原件，只创建 `deliverables/` 中的新文件；不会覆盖 V8.1。三张流程图由脚本生成 PNG 供 Word 嵌入，同时输出 SVG 供团队人工编辑。若编辑 SVG 后需要更新 Word，请同步修改脚本中的绘图定义并重建，以保持 PNG 与 SVG 的内容一致。
