# 图1—图7与论文视觉重构设计

日期：2026-09-03  
范围：固定 VS Code 解释器、重绘图1—图7、重建论文 DOCX/PDF；不修改数据清洗、模型、优化约束或已验证数值结论。

## 1. 目标与验收标准

本次修改解决图表风格松散、论文内嵌位图分辨率不足、图4缺少决策局部框，以及 VS Code 没有固定项目解释器的问题。

验收标准如下：

1. `.vscode/settings.json` 将默认解释器固定到 `${workspaceFolder}\\.venv\\Scripts\\python.exe`，并启用新终端自动激活环境；
2. 图1—图7共用一致的字体、配色、线宽、网格、图例、边距和刻度格式；
3. 每幅图同时生成 300 DPI PNG、矢量 PDF 和可编辑 SVG；
4. 图4标出 1.30% 主方案，增加局部放大框与连接标记，并在图注和正文中解释局部框用途；
5. 图表重构不得改变模型输出表和核心数值；
6. 新图嵌入论文后重新生成 DOCX/PDF，PDF保持A4且逐页检查无裁切、重叠、缺字和图例遮挡；
7. Ruff、Pytest、最小运行、全量运行以及生成物结构检查通过。

## 2. 方案比较与选择

### 方案A：仅提高PNG导出DPI

改动最小，但无法修复配色、网格、图例、坐标格式和图4表达不完整的问题，不采用。

### 方案B：统一主题并逐图优化

在现有 Matplotlib 管线中增加小型公共样式与保存函数，各图仍保留独立绘制逻辑。它能够统一外观，同时让每幅图采用适合自身数据结构的表达方式。本次采用该方案。

### 方案C：重建独立绘图框架

把所有图拆成新包并引入完整主题配置系统，扩展性更强，但对只有7幅图的项目属于过度设计，不采用。

## 3. 统一视觉规范

- 字体：优先使用 Microsoft YaHei，回退到 SimHei 和 DejaVu Sans；数学字符使用 Matplotlib 默认数学字体；
- 字号：坐标轴标题10.5 pt，刻度9 pt，图例9 pt，图内注释8.5—9 pt；论文图题继续由 Word 统一管理；
- 配色：采用色盲友好的深蓝、青绿、橙红、金色和中性灰，避免高饱和大面积填充；
- 线条：主线1.8 pt，辅助线1.0—1.2 pt；散点使用白色描边；
- 网格：只显示主网格，浅灰虚线、低透明度，置于数据下方；
- 坐标轴：隐藏上、右边框，保留浅灰左、下边框；刻度朝外；
- 图例：无厚重边框，不覆盖关键数据，必要时横排；
- 画布：单图6.6×4.2英寸，双图9.2×3.9英寸；使用受控边距和紧边界导出；
- 输出：白色背景，PNG为300 DPI；PDF保留TrueType字体，SVG保留可编辑文本；三种格式使用相同内容。

## 4. 各图表达设计

### 图1：源域与目标域CRI分布

使用共同分箱边界绘制半透明直方图和清晰轮廓，避免两组数据因分箱不同产生视觉偏差。图例写明样本数，并用竖虚线标出两组中位数。

### 图2：年利率—客户流失率

原始观测使用小型空心/半透明散点，保序拟合使用较粗实线；A、B、C级同时通过颜色与点形区分。纵轴使用百分比格式，横轴显示4%—15%。

### 图3：问题一预算—效益曲线

使用带描边的节点折线，标注各预算点的效益值，横纵轴以百万元表示。网格仅辅助读取，不加入额外拟合或外推。

### 图4：问题二风险—效益前沿

主图展示全部风险上限方案，并用星形突出1.30%主方案。局部框放大1.28%—1.34%附近的有效前沿，用于观察主方案附近的边际效益变化和1.34%后的平台起点；局部框不表示新增样本或第二套模型。正文补充这一用途说明。

### 图5：压力情景组合效益

按轻度、中度、重度从左到右绘制柱形图，颜色随压力增强由青绿过渡到橙红，柱顶直接标注效益值，使最坏情景一眼可见。

### 图6：全局SHAP重要性

按重要性由低到高绘制水平条形图，使用单一蓝色渐变或主蓝色，数值标注置于条形末端。保留“风险方向贡献”的准确含义，不解释为因果效应。

### 图7：LGD与压力强度敏感性

左右子图共享完整视觉规范，各自标注关键节点；左图展示LGD变化下的名义组合效益，右图展示压力强度变化下的最坏情景效益。面板标识采用“(a)”和“(b)”。

## 5. 代码与数据边界

绘图继续读取现有 `results/*.csv` 和模型运行内存结果，不引入新数据。公共样式、格式化和三格式保存逻辑保持为小函数；各图仍由当前绘图函数负责，避免改动建模与优化代码。新增 `figures/README.md`，逐图列出生成代码、输入数据、输出文件和图4局部框含义。

论文构建器改为读取 `figures/*.png` 的300 DPI图，不再依赖旧的约180 DPI中间图。旧 `paper/assets` 只作为历史中间目录，不作为新论文的数据源。
