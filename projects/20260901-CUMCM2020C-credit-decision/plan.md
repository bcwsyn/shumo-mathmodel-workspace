# 方案

## 项目定位

- 项目模式：高质量完整建模；用户于 2026-09-01 明确授权连续完成至论文初稿，最后集中验收。
- 题目：2020 年全国大学生数学建模竞赛 C 题“中小微企业的信贷决策”。
- 论文语言：中文。
- 排版载体：已验证主交付为 DOCX + Word 导出 PDF。原计划 Typst，但当前机器未发现 Typst 编译器；按环境约束未静默安装系统工具。
- 数据权威来源：本项目 `inputs/` 中 2026-09-01 固定的题面及三个附件。不得读取、复用或引用工作区任何旧题目的数据、代码、参数、模型或结论。

## 已确认技术路线

信用风险迁移评价 + 利率需求响应 + 多目标鲁棒优化 + SHAP 解释。

信誉评级是信用风险评价的主监督标签；违约字段仅用于外部有效性核验和授信约束，不宣称由 123 家小样本估计得到可靠的违约概率。附件 1 学得的“经营特征到信用风险”关系迁移至附件 2；附件 3 用于拟合利率对客户流失的需求响应。问题三在冲击情景集下求解收益、风险与客户覆盖之间的鲁棒授信组合。

## 成功标准

1. 输入文件哈希可验证，清洗与特征定义可复现。
2. 评级评价模型有分层交叉验证、基线对照、校准/稳定性检查及 SHAP 解释。
3. 三个问题的结果分别具有可行性、预算守恒、利率边界和风险约束校验。
4. 论文初稿中的每个数值可追溯到本项目的结果文件或图表。
