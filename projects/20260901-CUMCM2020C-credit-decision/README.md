# 2020C 中小微企业信贷决策：独立重做版

本项目从题面与三个原始附件重新完成建模、实验和论文初稿。唯一原始输入位于 `inputs/`，其 SHA-256 记录在 `MANIFEST.md`；项目没有把工作区旧题目的数据、代码、参数或结论作为计算输入。

## 技术路线

1. 从进销项发票构造 32 维经营特征；
2. 用 Logistic 与 XGBoost 融合完成有信贷企业的信用风险评价；
3. 冻结源域模型，将“经营特征到风险”的映射迁移到 302 家无信贷记录企业；
4. 对附件 3 的利率—客户流失关系作单调回归；
5. 分别求解名义授信组合和多情景 maximin 鲁棒组合；
6. 用 SHAP 解释全局风险驱动因素和高风险企业的局部贡献。

信誉评级是主监督标签。历史违约字段只用于外部有效性核验以及把评级平滑映射到组合风险损失尺度，因此本文不把输出解释为经过校准的企业个体违约概率。压力系数和 1.30% 组合风险上限是决策假设，已在论文和报告中明示。

## 主要交付物

- `results/`：逐企业策略、敏感性、场景结果和汇总 JSON；

- `REPRODUCE.md`：Windows/PowerShell 复现步骤。

## 核心结果

- 融合模型折外 Macro-F1 为 0.6086，二次加权 Kappa 为 0.6666；折外 CRI 对历史违约的 AUC 为 0.9066。
- 问题一在展示性 5000 万元预算下选择 50 家企业，全部为 A/B/C 级。
- 问题二在 1 亿元预算和 1.30% 风险上限下选择 101 家企业，期望效益 142.90 万元，预算误差为 0。
- 问题三在轻度、中度、重度三情景下的组合效益分别为 132.46、114.75、90.99 万元；重度情景为最坏情景。

这些数值是模型在当前数据与显式假设下的计算结果，不等同于真实银行业务中的已校准收益或损失预测。
