# 历史经验迁移检查

应用论文或方法卡前逐项检查：

1. 当前题目的决策目标是否相同，而非只看题材相似。
2. 数据粒度、单位、规模、缺失机制和时间范围是否兼容。
3. 历史模型的关键假设在当前数据上能否验证。
4. 目标函数与比赛评分要求是否一致。
5. 约束是否遗漏当前题目的新增条件。
6. 算法规模、时间和算力是否可接受。
7. 是否存在更简单、可解释的基线。
8. 是否会造成数据泄漏、过拟合、循环论证或权重主观化。
9. 评价指标能否反映当前问题的真实目标。
10. 迁移的是方法和验证流程，而不是历史数值或结论。
