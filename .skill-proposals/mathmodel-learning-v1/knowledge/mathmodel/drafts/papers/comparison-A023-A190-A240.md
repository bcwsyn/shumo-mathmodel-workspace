# A023 / A190 / A240 横向学习结论（草稿）

## 共同骨架

三篇都采用“集总压力—密度模型 + 质量守恒 + 孔口流量 + 离散仿真 + 参数搜索”，并按恒压供油、柱塞泵、双喷嘴/泄压阀逐级扩展。共同优点是物理主线统一、子问题衔接自然、结果可由代码生成；共同短板是验证不足、单位和实现细节易错、缺少工程可行域与数值收敛。

## 差异矩阵

| 维度 | A023 | A190 | A240 |
|---|---|---|---|
| 压力—密度 | 数值积分/查表思路 | 正文线性、代码非线性，前后冲突 | 非线性积分关系较明确 |
| 优化指标 | 目标压力平方偏差、稳态窗口 | 质量差、平均偏差等多种指标混杂 | 平均绝对偏差，末问改峰峰值 |
| 搜索 | 网格、拟合、交替搜索 | 逐级缩步长遍历 | 粗搜 + 细搜 |
| 稳健性 | 很弱 | 有扰动章节，但代码把扰动乘零 | 基本没有 |
| 可复现性 | 代码较多但缺 `.mat`，有疑似变量错误 | 代码完整度较高但单位/随机实现严重有误 | 代码较短，外部 Excel 依赖且内存开销大 |
| 写作 | 摘要和递进最好 | 机理论证较多但冗长 | 最紧凑、指标较清楚 |

## 对未来建模的组合建议

可借鉴 A023 的递进结构、A190 的策略对照意识、A240 的粗细搜索和明确偏差指标；不能继承任何一篇的参数数值、单位写法或全局最优表述。新模型至少应增加：

1. 统一量纲和状态方程的单一实现；
2. 工程可行域与控制频率上限；
3. 三档时间步收敛；
4. 零控制/简单规则基线；
5. 参数灵敏度和多次随机扰动；
6. 小规模独立复核或替代求解器；
7. 代码断言、单元测试和结果表格，而非只凭曲线判断。

## 反锚定规则

这三篇同题论文只提供历史候选思路。面对新赛题时，必须先独立完成题意和数据分析，再检索本卡；若当前题目的状态、目标、约束或数据结构不同，不得因“优秀论文用过”而选择相同模型。
