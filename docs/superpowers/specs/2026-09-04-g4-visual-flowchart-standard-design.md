# G4 高质量论文流程图规范设计

## 目标

将数学建模工作流 G4 的非数据图示阶段升级为可复用的高质量流程图制作流程。它要求图示先服务论文论证，再进行视觉设计；最终产物必须与当前论文、模型、代码和结果边界一致，并可编辑、可渲染、可复核。

## 适用范围

适用于技术路线图、模型结构图、求解流程图、变量关系图、指标体系图和决策闭环图。不适用于由结果数据直接绘制的折线图、柱状图、热图、散点图或敏感性图，这些仍属于 G3 数据图表阶段。

## 制作流程

1. **图示论证合同**：在制图前明确图的单一论证目的、正文或报告依据、读者应在三秒内获取的信息、必须出现的模块以及禁止出现的未经证实内容。
2. **图型与叙事结构**：根据论证目的选择主流程、因果树、决策闸门、层级结构或反馈闭环；先规划模块层级与箭头关系，再开始绘制。
3. **视觉语言**：每种主色只对应一种语义；实线箭头表示数据或决策主流，虚线表示反馈、条件或监控；使用克制的低饱和颜色、统一圆角/边框/字号和足够留白，不使用装饰性阴影、渐变、卡通图标或 AI 水印。
4. **源文件与导出**：简单且需要多人图形界面维护的图使用 Draw.io；复杂、高层级或需要精确排版的图使用 SVG。每张正式图必须保留可编辑主源，并导出 PDF 与高清 PNG；不得只交付截图。
5. **双重验收**：先核查图中文字、方法、数值和逻辑与当前证据一致；再将图实际渲染，检查文字清晰度、箭头避让、模块对齐、留白、裁切和最终排版尺寸下的可读性。发现问题时修改源文件后重新导出。
6. **记录与交接**：在 `reports/DRAWIO_REPORT.md` 中记录图的论证依据、源文件、导出物、视觉验收结果和论文嵌入建议。G4 仍需用户审批，审批前不自动写入论文正文。

## 强制边界

- 不得从参考论文、旧版本流程图或通用模板搬运当前论文没有的模型、指标、结论或数值。
- 参考图只可借鉴布局、层次、配色和表达方式，不能作为科学内容来源。
- AI 可协助提炼结构与检查视觉问题；正式图示必须保留人工可编辑的 SVG 或 Draw.io 源文件，并在图示记录中如实说明工具使用。
- 流程图不能替代结果图，不能使用装饰性图形掩盖缺少论证或证据的问题。

## 验收标准

1. 图在三秒内可识别主问题、主路径和最终输出。
2. 所有节点、箭头、颜色和反馈线有唯一且一致的含义。
3. 无箭头穿过核心节点、无文字裁切或明显重叠，缩至论文目标尺寸后仍可阅读。
4. 每个图示要素可回溯到当前工作区的论文、报告、代码或结果证据；没有证据的要素不进入正式图。
5. 主源、PDF、PNG 与生成记录齐全；未通过任一项则状态为 `UNVERIFIED` 或 `WAITING_FOR_APPROVAL`，不能写为已通过。

## 本次验证样例

“从预测到可信授信：中小微企业信贷决策闭环”采用了共同特征、风险与留存职责分离、联合配置、三道决策闸门和监控反馈五层结构。它在 SVG 中手工构建，实际渲染后将过粗箭头改为细线小箭头；该视觉修订不改变论文模型或数值。
